The Financial Budget App is a mobile application built with Kotlin for Android that empowers users to manage their personal finances efficiently. This app includes core budgeting tools such as category management, monthly budgeting, expense filtering, and receipt uploads.
Login
Secure login system for returning users.
 Validates credentials with error handling.
Option to redirect to registration screen.
Registration
New users can create an account by filling out a form.
Validation checks for password strength, email format, and empty fields.
Redirects to login screen after successful sign-up.
Categories
 Create, Edit, and Delete custom spending categories.
Categories are used to label and sort expenses (e.g., Groceries, Transport, Data).
Provides clear organization of transactions.
Filter Expense  
Filter expenses by date range using a date picker.
View only transactions that fall between selected 'From' and 'To' dates.
Helpful for generating monthly reports or budgeting reviews.
Receipt Upload
 Upload receipt images from device gallery.
 Useful for validating and documenting purchases.
Monthly Budget
 Set a total monthly budget.
 Add expenses that reduce from your budget total.
Visual indication when the budget is nearly or fully spent.
 

Recent Expenses
View a list of your most recent expense entries.
Each entry displays the date, category, description, and amount.
Automatically updates with each new transaction.
 Manage Budget
Set and adjust budget limits for specific categories.
Visualize how much you've spent in each category.
Get alerts when category spending exceeds its limit.
